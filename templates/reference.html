실태확인원은 정보 제공까지. 유형분류는 체납담당공무원이 내부정보 결합해 결정.

체납자 4유형
일시적 납부곤란자 TYPE 1
일시적 어려움(부도·재난·질병 등)으로 납부 곤란하나, 납부의지 있고 사업 정상화로 징수 가능한 자
강제징수·행정제재 보류, 분납 유도 / 탄력적 강제징수(국징법 §105②)
고의적 납부기피자 TYPE 2
납부능력 있으나 거부 또는 재산 타인명의 이전. 고액·상습체납자: 3회 이상 체납 + 1년 경과 + 2억원 이상
가택수색, 압류·공매, 사해행위 소송, 고발, 추적조사
생계 곤란형 체납자 TYPE 3
무재산·최저생계비 이하 소득자. 압류금지재산만 보유 또는 재산 없음
복지연계, 납부의무 소멸 검토
기타 TYPE 4
단순 무납부(체납사실 미인지) / 행방불명자(폐가·주민자치센터 주소)

01
기본 상황 · 납부불가
+
관찰 포인트
낡은 옷, 청결 불량, 주방 설거지·소주병 → 생계 곤란 시그널
핵심 멘트
확인원"독촉 아닙니다. 납부가 어려운 이유와 생활실태를 확인해 정리하는데 도움드리려고 방문했습니다."
처리
복지연계 의사 확인 → 신청 시 신청서 수령. 본인이 거부하면 그대로 종료, 강요 X.
02
분납 희망
+
관찰 포인트
단정한 옷차림, 사업·가게 운영, 일시적 자금경색
핵심 멘트
확인원"분납 가능하도록 도와드립니다. 체납안내문에 있는 체납담당공무원이 직접 전화드리도록 조치하겠습니다."
주의
분납 가능여부·금액 결정은 체납담당공무원 권한. 실태확인원이 약속 X.
03
생계 곤란 · 복지연계
+
관찰 포인트
건강 악화, 전기·수도 체납, 단기 일용직, 쾌쾌한 냄새
핵심 멘트
확인원"생계가 어려우시면 자치단체 복지부서에 연결해드립니다. 신청하시겠어요?"
처리
복지연계신청서 + 개인정보 수집·이용 및 제3자 제공 동의서 수령. 복지위기알림(앱) 등록은 운영담당자 또는 현장 직접 입력.
04
고의적 납부기피 의심
+
관찰 포인트
고급 주택단지, 명품 의상, 골프백, 고가 인테리어. "사업 망함" 주장하나 배우자가 부담.
핵심 질문
확인원"수입이 없으신데 배우자분이 사업을 크게 하시나 보네요. 생활비는 배우자분이 부담하시는 거죠?"
처리
실태확인표 종합의견란에 고의적 납부기피 의심으로 분류. 배우자 명의 부동산 등 추적조사 필요성 메모. 체납담당공무원 분석 회부.
05
집안 상담 거부
+
대응
확인원"집안이 불편하시면 밖에 상담 가능한 장소로 이동해도 괜찮습니다. 근처 공터로 이동하시죠."
참고
제3자 영향 받지 않는 단둘 상담이 원칙. 외부 이동도 동일하게 적용.

+
대응 1단계

통화 연결되면
확인원"통화로 드릴 말씀이 아니라서 다시 댁으로 방문드리겠습니다. 언제 가능하실까요?"
번호 안 알려주면
강요 X. 체납안내문(연락처)을 제3자에게 전달 부탁하고 종료.

전원 부재 (거주는 함)
+
절차

처리

08
비거주 의심 (행방불명)
+
시그널

확인 방법 (아파트)
조끼 벗고 1인만, 옛 직장동료/지인으로 가장. "아직 여기 사나요?" 정도만.
처리
행방불명 의심으로 보고. 종합의견란에 비거주 메모.
09
폭언
+
초기 대응
확인원"화나시더라도 욕설은 자제 부탁드립니다. 도움드리려고 방문한 것입니다."
계속 욕설 시
확인원 1인 휴대폰으로 동영상 촬영(녹음 포함) 시작.
통제 불가 시
"대화가 되지 않을 것 같으니 돌아가겠습니다" → 즉시 이탈. 따라오면 인파 많은 곳으로 + 경찰 신고. 종료 후 지방청 운영담당자 보고.
10
위협 / 폭력 발생
+
즉시 조치
확인원"지금 행동은 폭행죄에 해당될 수 있어, 계속 이러시면 경찰에 신고하겠습니다."
동시 진행
즉시 1인 휴대폰 동영상(녹음 포함) 촬영. 무력 동원 시 동의 불필요.
대피
진정 안 되면 즉시 이탈. 따라오며 위협 시 경찰 신고 + 인파 많은 곳. 출동 시까지 회피.
사후
지방청 운영담당자 보고 후 필요 조치(진단서·경찰 진술 등).

  • "가산금 억울" · 고지서 뒷면에 명시. 독촉고지서까지만 법적 의무, 이후 안내문은 의무 X.
  • "완납했다" · 실시간 연계로 미수납 확인. 납부영수증 제출이 원칙.
  • "부과 자체 이의" · 체납담당공무원에게 상세 상담 안내.
  • "개인정보 열람 가능?" · 강제징수·민감정보 X, 활동에 필요한 최소 정보만. §116 2천만원 처벌 강조.
  • "공무원 아닌데 왜?" · 국세청 고용 공무 중 / 단순·반복 보조 업무 / 비밀유지 보안각서 + 상시 모니터링.
  • "이름 크게 부름" · 호수 못 찾아 발생, 사과 + 재발 방지.
  • "제3자 발설했다" · 부재 시에도 가족 포함 누설 금지 원칙 재확인 + 사과.
  • "비거주인데 반복 방문" · 실거주자 확인 안 되어 재방문. 향후 비거주 분류 약속.
